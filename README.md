# Parkour Paradise 3 Fork

这是 [Hielke Maps 的 Parkour Paradise 3](https://hielkemaps.com/maps/parkour-paradise-3) 地图的数据包修改版。原地图包含 100 个跑酷关卡，支持单人和多人游玩。

本项目修复了练习模式的成绩判定：一轮挑战中使用过练习模式，本轮成绩就不再计入个人最佳纪录和评级进度。退出练习模式后，重新开始一轮即可正常记录成绩。

## 安装

1. 下载原地图，使用地图对应的 Minecraft Java 版打开存档。
2. 将本仓库中的 `main`、`more_maps`、`random`、`time`、`training_mode` 五个文件夹复制到地图存档的 `datapacks` 目录，替换同名数据包。
3. 重新进入世界，或由管理员执行 `/reload`，然后开始新一轮挑战。

## 常用命令

在游戏聊天栏输入以下命令，保留表中的大小写。

| 命令 | 用途 |
| --- | --- |
| `/trigger restart` | 回到起跑准备位置，重置本轮进度和计时，保留个人最佳纪录。 |
| `/trigger reset` | 返回大厅，重置本轮进度和计时，退出练习模式，保留个人最佳纪录。 |
| `/trigger training_mode` | 开启练习模式，再次输入即可关闭。 |
| `/trigger to_level set 42` | 在练习模式下前往第 42 关。将 `42` 换成想去的关卡编号，范围为 1～101。 |
| `/trigger show_PB` | 查看个人最佳通关时间（PB）。 |
| `/trigger reset_PB` | 清除个人最佳纪录和评级进度。 |
| `/trigger ranks` | 查看各评级对应的通关时间要求。 |

## 练习模式

开启后，快捷栏的第 1、5、8、9 格会换成练习道具。

输入 `/trigger to_level set 42` 可以直接前往关卡检查点，同时更新复活点。71 和 72 共用一个大关，选择 72 会前往 71；100 是过渡路段，选择 100 会前往 101。跳关会停止当前的练习计时，保存的位置保持不变。

| 道具 | 操作 |
| --- | --- |
| 黏液球 / 岩浆膏 | 右键开始 / 停止练习计时。计时中交换主副手可暂停或继续，默认按键为 `F`。 |
| 羽毛 | 右键切换飞行。普通地图环境下，开启飞行会切换为创造模式，关闭后恢复冒险模式。 |
| 海洋之心 | 右键保存当前位置和朝向，再次保存会覆盖上一个位置。 |
| 下界之星 | 右键回到保存的位置。 |

练习计时与整轮通关计时分开计算。练习过的这一轮仍会显示通关时间和评级，并提示成绩不计入纪录。即使在到达终点前关闭练习模式，这轮的成绩资格也不会恢复。

想挑战正式成绩时，先关闭练习模式，再输入 `/trigger restart` 重新起跑。
